Welcome

How this site works

This site was built from scratch with HTML, CSS, and (mostly) vanilla JavaScript. Everything you see from the UI to the animations at the top of the page were built from scratch. Besides some jQuery and p5.js (a 2D graphics library) for the animations, no external libraries or design systems were used.

The end goal here is for this site to be fully customizable, so every user could get a unique experience when they refresh the page. So far you can change the color scheme and the animations at the top of the page - down the line, a custom theme / look and feel too. Stay tuned for future updates!
